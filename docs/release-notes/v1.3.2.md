## Line generator: lines arrive checked, so you only verify them

Generated combo lines in the **Line Trainer** are now built from your whole deck and checked card by card before you see them.

### New
- **Generate lines** (Line Trainer → Lines). There are two ways to run it:
  - **With Claude:** copy a prompt built from your full deck, run it in Claude Code or claude.ai (works on a Claude subscription), and paste the answer back.
  - **On the server:** used when an Anthropic or Gemini API key is configured. It finds your starters, writes one line per starter, repairs it, and runs a second pass that judges it against the card text.
- **Checked before you see them.** Every line is replayed card by card. It's flagged if it:
  - uses cards you don't run, or more copies than you run;
  - uses a card from a zone it isn't in;
  - reuses a once-per-turn effect, or Normal Summons twice;
  - uses wrong Link, Xyz or Synchro materials;
  - breaks a summon or "can't activate effects" restriction;
  - lists an end board the steps never build.
- **Fix-up prompt.** Lines that fail come with a fix-up prompt to paste back into Claude. Fixed lines replace the flagged drafts.
- **One-tap verify.** Each line shows ✓ Checks passed, ⚠ to look at, or ✕ problems. Play it once in Master Duel, then tap **Works — mark verified**, or **Needs a fix** to edit it.

### Improved
- Generated lines now see your **Extra Deck** and **full card text**. The old AI drafts saw neither.
- Interruption branches target the hand traps most played in current top lists.

### Fixed
- The server's database setup can now run on a brand-new database.

### Known limits
- The checker isn't a full rules engine. It doesn't model chains or missing the timing, so playing a line once is still the final check.
- Generated lines don't replace the AI drafts you imported in 1.3.1. Delete any of those you no longer want.
