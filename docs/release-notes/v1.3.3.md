## Pasting generated lines from a chat now works

### Fixed
- **Import & check** no longer fails with "Couldn't read that as JSON: Expected ',' or '}'…" when you paste lines copied from Claude Code or claude.ai.
  - Copying from a chat drops the backslash before quotes inside the text (for example `Maxx "C"`), which made the JSON invalid.
  - The importer now repairs those quotes, and also turns curly quotes from a phone keyboard into straight ones.
- The generate prompt now asks for single quotes inside text and for the answer in a ```json code block, which keeps it intact when copied.

### Improved
- The Dark Magician example lines now cover 8 opening hands, adding Rod + Apprentice and Magicians' Souls + Rod. They also branch for Maxx "C", Droll & Lock Bird and Ghost Ogre.

### Note
- The fix runs on the server, so it works in the 1.3.2 app as soon as the server updates. The new APK just keeps versions in step.
