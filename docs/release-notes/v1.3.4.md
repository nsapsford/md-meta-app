## More reliable line imports

### Fixed
- **Import & check** now repairs quotes inside pasted text much more reliably.
  - If its quick fix fails, it re-reads the text, fixes the stray quote at each place reading stops, and tries again.
  - Tested on 300 Dark Magician line sets with quotes added and backslashes stripped: every one came back exactly as written.
- If an import still fails, the error now says "importer v3" and shows the text around the problem, so it's quick to diagnose.

### Added
- `/api/health` now shows which server build is live (`commit`).

### Note
- These fixes run on the server, so any 1.3.x app gets them once the server updates.
