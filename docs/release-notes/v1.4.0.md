## Real per-rank numbers, and no more made-up matchups

### Fixed
- **Matchups were not real.** Every deck showed the same four "opponents" (Bystial, Tearlaments, Spright, Swordsoul). Those numbers were really the deck's win rate at different ranks. They are gone.
- **Ladder EV and Pick Strategy** no longer rank decks from guessed matchups.
- Sample sizes on the tier list now count each game once.

### Added
- **Rank filter on the tier list** (Bronze to Master): win rate and play rate for the rank you pick.
- **Ladder EV now uses Master-rank results.** Each deck shows its measured Master win rate (with mirror matches taken out), play rate, win rate going first and second, number of games, and a flag when the sample is small.
- **New endpoint** `GET /api/meta/by-rank?rank=master` for those numbers, for any rank.

### Changed
- **Matchups**, **Ecosystem** and **Meta Advisor → By Deck** now say when there is no matchup data, instead of showing estimates as if they were results. Untapped doesn't publish deck-vs-deck win rates, so these fill in only from the games you log under **My Games**.
- The Matchups matrix starts with **Infer Gaps** off. Turning it on shows model estimates, marked as such.
- Untapped sync can refresh its login token on its own.

### Note
- After updating, the per-rank numbers appear after the next Untapped sync (twice daily, or run it manually).
- MD Board Scanner for Windows is a separate download (`mdscan-latest`).
